# Домик в лесу — Прототип 0

Одноразовый браузерный прототип: проверяем один короткий игровой цикл.
Полное ТЗ — в [SPEC.md](SPEC.md).

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Откроется адрес вида http://localhost:5173 — это и есть игра.

## Управление

- Клик по земле — идти туда.
- Клик по объекту — подойти к нему (дом — войти, дверь внутри — выйти).
- WASD или стрелки — ходить напрямую.
- Клик по спелой грядке — выкопать картофель; по пустой — посадить; ещё клик — полить, тратит 1 воду из ведра (вырастет к утру).
- Клик по пню — удар топором (3 удара — 2 дров, пень отрастёт через день).
- Клик по ручью — зачерпнуть воды (в ведре до 3).
- Клик по печи или плите в доме — меню готовки (печёный картофель, суп). Готовится 1 игровой час (в доме часы идут медленнее, поэтому удобнее выйти и заняться делами). Готовое — забрать кликом.
- Кнопка «Связать дрова» в инвентаре — 5 дров в связку.
- Почтовый ящик: утром в нём письмо от Агаты с заказом (флажок поднят). Туда же можно положить готовый заказ — деньги придут следующим утром письмом.
- Бабушка Агата стоит у калитки с 17:00 до 21:00: заказ из рук в руки — деньги сразу и пирожок в подарок.
- Список текущих заказов — слева под часами. Несданный заказ переходит на следующий день.
- Доска улучшений у крыльца — купить фонарь за 120 монет: ночью тёплый свет, мотыльки, тихий треск фитиля.
- Клик по кровати в доме — лечь спать: «Итоги дня», затем вопрос «Ещё день?». После дня 3 — экран «Конец прототипа».
- Клавиша ` (Ё) — панель отладки: ускорить время ×4, перейти к дню N, дать ресурсы и 100 монет, скачать журнал, сброс.

На улице 1 игровой час = 24 секунды, в доме часы идут в 4 раза медленнее, в меню стоят. В 2:00 герой сам идёт домой спать.

## Где что лежит

- `src/config.json` — все числа и тексты (размеры, позиции, скорость, камера, цвета, надписи).
- `src/world/` — участок и комната в доме из примитивов.
- `src/nav/` — проходимость и поиск пути.
- `src/game/` — часы, свет, инвентарь, добыча, готовка, заказы, журнал событий.
- `src/player.ts`, `src/camera.ts`, `src/input.ts` — герой, камера, ввод.
- `src/ui/` — HTML-оверлеи поверх картинки.
- `src/fx/` — отклик: звуки, частицы, squash.
- `public/sfx/` — звуки Kenney (CC0), источники в [CREDITS.md](CREDITS.md).

## Журнал событий

Каждое действие (добыча, удары по пню, посадка, полив, готовка, сдача заказа ящиком или из рук в руки, оплата, покупка, сон, ответ на «Ещё день?») записывается с реальным и игровым временем.
Кнопка «Скачать журнал» есть на финальном экране и в панели отладки — сохраняется файл `little-house-log-ГГГГММДДЧЧММ.json`.
Журнал живёт только в открытой вкладке: в сеть ничего не отправляется, после перезагрузки страницы он начинается заново.

## Публикация на Cloudflare Pages

Сборка — обычные статические файлы в папке `dist`.

Один раз войти в Cloudflare (откроется браузер):

```bash
npx wrangler login
```

Один раз создать проект:

```bash
npx wrangler pages project create little-house-proto0 --production-branch main
```

Собрать и выложить:

```bash
npm run deploy
```

Ссылка на игру: https://little-house-proto0.pages.dev

Проверить сборку локально перед выкладкой:

```bash
npm run build
npm run preview
```
