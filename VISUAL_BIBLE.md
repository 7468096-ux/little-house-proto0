# «Домик в лесу»: визуальная библия и задание на внедрение

> **Для Claude Code.** В этом файле две части:
> **часть A** — визуальная библия (как игра должна выглядеть),
> **часть B** — задание (что сделать в коде).
> Эталон картинки — `reference/target_frame.png`. Все решения проверяй по нему.
> Движок и стек используй те, что уже стоят в проекте. Новый движок не тащи.

---

## Часть A. Визуальная библия

### A1. Суть образа одной фразой
Тёплый поздний вечер (golden hour) на лесной поляне. Низкое солнце пробивается сквозь деревья. Игрок смотрит сверху вниз на маленький уютный мир, который хочется трогать руками.

### A2. Ключевые принципы (в порядке важности)
1. **Свет решает всё.** Тёплое низкое солнце и длинные мягкие тени. Тени холоднее и зеленее света.
2. **Пятна света и тени крупные.** Поляна выглядит как лоскуты: солнечные пятна чередуются с тенью от деревьев, в том числе от тех, что за кадром.
3. **Низкий полигонаж, плоские грани.** Ёлки, камни и пни гранёные (flat shading). Мелких деталей в геометрии нет.
4. **Ограниченная палитра.** Тёплые зелёные, охра, тёплое дерево, кремовые стены. Чисто-серых и чисто-чёрных цветов нет: даже тени окрашены.
5. **Мягкость.** Края теней мягкие, контраст умеренный, лёгкая дымка и виньетка.

### A3. Камера
- Высокий изометрический ракурс: наклон вниз примерно **45–50°**, поворот примерно **45°** по горизонтали.
- Перспектива с узким FOV (**25–35°**). Можно ортографическую камеру, если в прототипе уже она.
- Домик примерно в центре кадра и занимает около 15–20% площади экрана.

### A4. Свет
| Параметр | Значение (стартовое) |
|---|---|
| Солнце, цвет | `#FFD9A0` (тёплый персиковый) |
| Солнце, интенсивность | высокая: свет явно доминирует |
| Солнце, высота | низкая, **~25–35°** над горизонтом |
| Солнце, направление | сзади справа, относительно камеры; тени уходят **вниз влево** по кадру |
| Небесный/ambient свет | `#7FA37A` (зеленовато-холодный), слабый |
| Цвет «от земли» (hemisphere ground) | `#3A4A2A` |
| Тени | мягкие (PCF soft / VSM), размытие среднее, плотность ~70–80% |
| Ambient occlusion | заметный: темнит стыки домика с землёй, основания ёлок и камней |

**Пятна света.** Над сценой стоят невидимые «тенеотбрасыватели» (кроны за кадром) или работает текстура-cookie на солнце, чтобы на траве были крупные пятна тени. Это важно для атмосферы, как туман.

### A5. Палитра (сняты пипеткой с эталона, приблизительно)
| Роль | Свет | Тень |
|---|---|---|
| Трава | `#999C37` / `#BFAA49` (в солнце почти `#E2C05B`) | `#42532F` / `#2F472E` |
| Ёлки (хвоя) | `#807B3F` → `#999C37` на гранях к солнцу | `#394C2E` / `#223427` |
| Тропинка | `#E2B46A` | `#C89355` |
| Стены дома | `#EADBC2` | `#B8A88E` |
| Крыша | `#4A4E58` (графит, слегка синий) | `#33363E` |
| Дерево (дверь, рамы, вывеска, грядки) | `#8A5A32` | `#4A3020` |
| Земля на грядках | `#5A3A22` | `#3A2616` |
| Камни | `#B8B2A2` | `#7E7868` |
| Вода | `#33826C` | `#24595B` |

Правила работы с палитрой:
- У каждого материала два цвета: светлый и теневой. Оттенок теней сдвинут к зелёному или синему.
- Все модели (в том числе из Meshy и Tripo) перекрашиваются в цвета палитры. Их собственные текстуры не используем, либо приглушаем.

### A6. Материалы
- Основа: **плоский цвет + flat shading**, без PBR-блеска. Roughness ~0.9–1.0, metalness 0.
- Допустим лёгкий вертикальный градиент на траве и стенах, но без шумных текстур.
- На траве мелкие кустики-«звёздочки» и травинки (инстансинг), чтобы поверхность не была пустой.

### A7. Атмосфера и пост-обработка
| Эффект | Значение (стартовое) |
|---|---|
| Туман | цвет `#C9B98A` (тёплая дымка), линейный или экспоненциальный, слабый: дальний план чуть выцветает |
| Tone mapping | ACES Filmic (или аналог), exposure ~1.0–1.1 |
| Цветовая температура | смещена в тёплую сторону |
| Насыщенность | +5–10% |
| Контраст | умеренный, тени не проваливаются в чёрный |
| Bloom | очень слабый, только на самых ярких бликах (вода, солнечные пятна) |
| Виньетка | мягкая, ~0.25–0.35 |
| Lift теней (shadow tint) | тени тонируются в `#2A3A2A` |

### A8. Чего НЕ делать
- Холодный синий свет днём, серые тени.
- Глянцевые и металлические материалы.
- Высокополигональные или фотореалистичные ассеты рядом с low-poly.
- Резкие чёрные тени.
- Пёстрые цвета вне палитры.

### A9. Время суток (пресеты)
Эталон соответствует пресету **`goldenHour`**. Нужны ещё три пресета, выдержанные в той же гамме:
- `morning`: солнце выше, свет светлее и чуть прохладнее (`#FFF1D6`), туман слабее.
- `day`: солнце высоко, свет почти белый с тёплым оттенком, тени короче.
- `night`: луна `#8FA8D8`, слабая; ambient тёмно-сине-зелёный; окна домика светятся тёплым `#FFB860`.

## Часть B. Задание для Claude Code

### B1. Цель
Привести картинку прототипа к эталону `reference/target_frame.png` и **вынести все визуальные параметры в один конфиг**, чтобы автор крутил их сам, без правок кода.

### B2. Конфиг
Создай файл `config/visual.json` (или аналог в принятом в проекте формате). Код **не содержит** зашитых значений цвета, света, тумана и пост-обработки: всё читается из конфига. Примерная структура:

```json
{
  "activePreset": "goldenHour",
  "camera": { "fov": 30, "pitchDeg": 48, "yawDeg": 45, "distance": 40, "orthographic": false },
  "presets": {
    "goldenHour": {
      "sun":     { "color": "#FFD9A0", "intensity": 3.0, "elevationDeg": 30, "azimuthDeg": 135 },
      "ambient": { "skyColor": "#7FA37A", "groundColor": "#3A4A2A", "intensity": 0.6 },
      "shadows": { "enabled": true, "mapSize": 2048, "softness": 4, "bias": -0.0005, "darkness": 0.75 },
      "lightPatches": { "enabled": true, "scale": 1.0, "strength": 0.6 },
      "fog":     { "color": "#C9B98A", "near": 40, "far": 140, "density": 0.008 },
      "post": {
        "toneMapping": "ACES", "exposure": 1.05,
        "saturation": 1.08, "contrast": 1.0, "temperature": 0.15,
        "shadowTint": "#2A3A2A",
        "bloom": { "enabled": true, "strength": 0.15, "threshold": 0.9, "radius": 0.4 },
        "vignette": { "enabled": true, "amount": 0.3 },
        "ao": { "enabled": true, "radius": 0.6, "intensity": 1.0 }
      }
    },
    "morning": { "...": "по A9" },
    "day":     { "...": "по A9" },
    "night":   { "...": "по A9", "windowGlow": { "color": "#FFB860", "intensity": 2.0 } }
  },
  "palette": {
    "grass":  { "light": "#999C37", "shadow": "#42532F" },
    "pine":   { "light": "#807B3F", "shadow": "#394C2E" },
    "path":   { "light": "#E2B46A", "shadow": "#C89355" },
    "wall":   { "light": "#EADBC2", "shadow": "#B8A88E" },
    "roof":   { "light": "#4A4E58", "shadow": "#33363E" },
    "wood":   { "light": "#8A5A32", "shadow": "#4A3020" },
    "soil":   { "light": "#5A3A22", "shadow": "#3A2616" },
    "stone":  { "light": "#B8B2A2", "shadow": "#7E7868" },
    "water":  { "light": "#33826C", "shadow": "#24595B" }
  },
  "materials": { "roughness": 0.95, "metalness": 0.0, "flatShading": true }
}
```

Имена ключей можно адаптировать под движок, но смысл и группировка должны сохраниться.

### B3. Панель настройки в игре
- Добавь в существующий встроенный редактор (или отдельной панелью по клавише, например **F2**) **панель визуала** со всеми параметрами конфига: ползунки, color picker'ы, переключатели, выбор пресета.
- Изменения применяются **сразу**, без перезапуска.
- Кнопки: **«Сохранить в конфиг»** (записывает текущие значения в `visual.json` или отдаёт файл на скачивание, если запись на диск невозможна), **«Сбросить к пресету»**, **«Скопировать JSON»**.
- Для веба подойдёт `lil-gui` или `Tweakpane`. Для другого движка подбери аналог.

### B4. Режим сравнения с эталоном
- Кнопка или клавиша (например **F3**), которая показывает `reference/target_frame.png` поверх игры с регулируемой прозрачностью, плюс режим «половина экрана — эталон / половина — игра».
- Кнопка **«Иконка»**: оба изображения уменьшаются до ~200 px по ширине и показываются рядом, чтобы сравнивать пятна света и цвета.

### B5. Материалы и ассеты
- Все материалы берут цвет из `palette` по роли (`grass`, `pine`, `wood` и т. д.). Роль задаётся у объекта.
- Импортированные модели (Meshy, Tripo) при загрузке получают материал своей роли из палитры. Оригинальная текстура отключается или смешивается с цветом палитры (параметр `textureMix` 0–1 в конфиге).
- Flat shading и roughness берутся из `materials`.

### B6. Порядок работы
1. Вынести все текущие зашитые визуальные параметры в `visual.json`, ничего не меняя во внешнем виде.
2. Панель настройки (B3) и сравнение с эталоном (B4).
3. Выставить пресет `goldenHour` по части A: свет, тени, туман, пост-обработка.
4. Пятна света на траве (A4).
5. Палитра и материалы (B5).
6. Пресеты `morning`, `day`, `night`.

После каждого шага сделай скриншот игры рядом с эталоном и кратко напиши, что совпадает, а что ещё нет.

### B7. Критерии готовности
- В коде нет зашитых значений цвета и света: всё в конфиге.
- Любой параметр меняется в панели и применяется на лету, а потом сохраняется.
- В режиме «иконки» игра и эталон читаются как одна и та же картинка: тёплый свет, зелёные тени, пятна солнца на траве, мягкая дымка.
- FPS не ниже, чем был до изменений; если тяжёлые эффекты (AO, bloom) просаживают, у них есть переключатели в конфиге.
